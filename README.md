# 陳泳幸 AI 顧問系統品牌網站

這是一個靜態企業顧問官網範例，品牌定位為「陳泳幸 AI 顧問系統」。網站主軸是協助企業建立 AI 策略、主管課程、顧問陪跑、流程導入與治理制度。

## 本次優化重點

- 強化第一屏視覺與品牌識別，讓首頁更像高端企業顧問官網。
- 補強課程方案區，包含主管簡報、企業內訓與流程工作坊。
- 新增顧問服務區，呈現 AI 導入藍圖、用例篩選、Champion 培訓與成效回顧。
- 強化立即預約區塊，以電子郵件作為諮詢入口。
- 優化手機版閱讀效果，讓 CTA、卡片與內容在小螢幕上維持清楚層級。

## 檔案結構

- `index.html`：網站內容、品牌訊息、課程方案、顧問服務與立即預約區塊。
- `style.css`：高端深色視覺、企業顧問風格版面、響應式與手機閱讀樣式。

## 使用方式

直接在瀏覽器開啟 `index.html` 即可預覽，不需要建置流程或後端服務。

## 合規備註

此版本沒有加入付款功能、不要求信用卡，也沒有串接任何收費服務。預約諮詢入口僅使用 `mailto:` 電子郵件連結。
