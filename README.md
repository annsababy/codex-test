# 陳泳幸 AI 顧問系統

一個簡潔、專業、高端顧問感的一頁式網站專案，主題為「陳泳幸 AI 顧問系統」。網站不包含付款功能、信用卡要求，也未串接任何收費服務。

## 專案內容

- `index.html`：網站主要 HTML 結構與文案內容
- `style.css`：響應式視覺設計與版面樣式
- `README.md`：專案說明文件

## 網站區塊

1. 主標題：陳泳幸 AI 顧問系統
2. 副標題：把 AI 變成效率、品牌與收入
3. 專業定位：AI教育與品牌顧問、企業創辦人、專業講師
4. 課程特色：AI工作術、品牌文案、招生系統、企業內訓
5. 適合對象：企業主、講師、補教業、社團領導人、個人品牌經營者
6. 三種方案：入門課、顧問課、企業內訓
7. 報名按鈕：立即預約諮詢

## 使用方式

直接用瀏覽器開啟 `index.html` 即可預覽網站。

如需替換預約信箱，請修改 `index.html` 中「立即預約諮詢」按鈕的 `mailto:` 連結。
